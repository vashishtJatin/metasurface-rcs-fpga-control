# metasurface-rcs-fpga-control
Technical internship project at NIT Jalandhar focused on the design and simulation of active PIN-diode-controlled coding metasurfaces for Radar Cross Section (RCS) reduction. The work involved CST Microwave Studio simulations, S-parameter and reflection-phase analysis, polarization conversion, 8×8 array, and FPGA/Verilog-based PIN-diode control.
